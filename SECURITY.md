# Security Policy

## Supported version

The `main` branch is the supported version of this project.

## Reporting a vulnerability

Do not report potential vulnerabilities in a public issue. Use GitHub private vulnerability reporting when available. If it is unavailable, email [thisaimentor10@gmail.com](mailto:thisaimentor10@gmail.com) with the subject `Security report: Plain Language Product Copy`.

Include a description, affected files or behavior, steps to reproduce, and a suggested mitigation if you have one.
