# Contributing

Thank you for improving Plain Language Product Copy.

## Contribution principles

- Preserve factual accuracy, material limits, privacy, and informed choice.
- Ground wording changes in a real reader problem.
- Include context for new examples: audience, surface, and intended outcome.
- Avoid broad rewrites that make the skill harder to maintain.

## Local validation

```bash
python3 scripts/validate_skill.py \
  skills/plain-language-product-copy \
  dist/plain-language-product-copy.zip
```

## Pull requests

- Keep each pull request focused.
- Explain the reader impact and any trade-offs.
- Update examples or quality gates when behavior changes.
- Confirm that the validation workflow passes.

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
